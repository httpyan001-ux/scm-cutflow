# 📁 Telegram Clip Library — MAGIC REEL AI source

MAGIC REEL AI ဒီ folder ၂ ခုထဲက clip တွေကို **random** ဆွဲပြီး
၁ မိနစ်ဝန်းကျင် viral short တစ်ပုဒ် ပေါင်းစပ်ထုတ်ပေးသည်။

```
Telegram Clip/
├── FUNNY/            ← ရယ်စရာ clip အတိုများ (.mp4 .mov .webm .mkv)
└── Accident(CCTV)/   ← CCTV မတော်တဆမှု clip များ
```

## သုံးနည်း
1. Telegram ကနေ ရလာတဲ့ clip တွေကို သက်ဆိုင်ရာ folder ထဲ ထည့်ပါ
2. ဖိုင်နာမည်မှာ ဖော်ပြချင်တဲ့ စာသားထည့်နိုင် — ဥပမာ `cat-fail-funny.mp4`
3. Dashboard → **MAGIC REEL AI** → FUNNY သို့ ACCIDENT ရွေး → ONE-CLICK GENERATE

## မှတ်ချက်
- clip တစ်ခုချင်း **၃–၂၅ စက္ကန့်** အကောင်းဆုံး
- ဖိုင်မရှိရင် စနစ်က **demo clip pool** ကို အလိုအလျောက် သုံးမည် (UI စမ်းသပ်ရန်)
- folder နာမည်ကို `.env` မှာ `CLIP_LIBRARY_DIR` ဖြင့် ပြောင်းနိုင်သည်
